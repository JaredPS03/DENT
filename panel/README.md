# Panel de Axon Dental

Next.js (App Router), TypeScript estricto y Tailwind. Se diseña primero para el celular (360 px) y se instala como PWA.
Las reglas de este panel están en `.claude/rules/panel.md`; las pantallas llegan en el hito 1E.

```bash
pnpm dev        # http://localhost:3000
pnpm lint
pnpm typecheck
pnpm build
```
